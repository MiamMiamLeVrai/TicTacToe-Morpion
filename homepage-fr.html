Contenu principal

Le célèbre jeu jouable sur le web !

Et si je vous disais que jouer au Morpion sur papier, est terminé ? Avec ce site, je peux vous affirmer que vous allez abandonner la version papier 👀. Il vous suffit juste de trois fois rien : un écran, un endroit paisible, une simple connexion internet et c'est tout. Fini tous ces moments ou vous deviez sortir une feuille, un crayon ou un stylo pour jouer, puis une fois que votre feuille est remplie d'une vingtaine de grille, trouver une place sur cette même feuille. Et si vous n'en trouvez pas, devoir chercher une autre feuille vierge pour gribouiller, et de recommencer encore et encore, jusqu'à n'en plus finir… pauvres arbres qui ont du subîr tous ces coups de crayons et stylos 😔.

Les différents modes de jeu

Bien évidemment il y aura différents modes de jeu disponibles, mais avant de vous jeter dans le vif du sujet, TOUS les modes de jeu ont une seule et même règle identique : deux joueurs maximums doivent placer les symboles (X et O) dans une grille. Celui qui aligne ses symboles identiques gagne la partie : un jeu simple pour une règle simple… KABOUM !!! 🤯. D'ailleurs dans cette base on peut imaginer plusieurs modes : une version classique (qui correspond au mode Joueur VS Joueur), un mode contre une IA, un mode 5x5 (qui est ENFIN disponible), etc. Bref, plein d'idées qui peut sortir du cerveau d'un développeur web. Avec tout ça, si vous dites que vous vous ennuyez, je sais pas quoi faire de plus…

C'est le moment de lancer une partie !

Ça y est, nous y sommes, il est temps de passer aux choses sérieuses et de vous lancer dans le vif du sujet 😎 ! Juste en-dessous, vous avez un bouton qui amène à un catalogue de modes de jeu disponibles, ou sinon dans la barre de navigation si vous êtes dans une autre page. Et tout ça directement sur votre navigateur, pas besoin d'installer des applications inutiles et douteuses, faites moi confiance 😉.
